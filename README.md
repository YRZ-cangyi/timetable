# 我的课表 · 手机端课表网站

**网址：<https://yrz-cangyi.github.io/timetable/>** —— 手机浏览器输入就能打开，不装 App。

纯前端静态网站：所有解析和存储都在你的浏览器里完成，服务器上只有页面文件，没有你的数据。

## 怎么用

- **Android 手机**：用 Chrome 打开上面的网址 → 右上角菜单 →「添加到主屏幕」，之后点桌面图标就能进，和 App 用起来一样。
- **电脑**：浏览器直接打开同一个网址。
- **离线备份 / 本地预览**：文件夹里双击 `index.html` 也行（功能完全相同，只是地址是 `file://`，数据跟网址版的互不相通）。

建议第一次打开后先在「设置」里点一次 **导出 JSON**，留一份备份。

## 功能

| 功能 | 说明 |
| --- | --- |
| 周课表 | 第 1 周周一按 `2026-09-07` 计算，星期一到星期日全显示 |
| 换周 | 左右滑动屏幕，或点顶部的 `‹` `›`；`本周` 一键回到当前周 |
| 看详情 | 点任意一节课，弹出名称、时间、地点、第几节、哪些周、备注 |
| 编辑 | 详情里点“编辑”，可改名称、老师、地点、星期、节次、周次、颜色、备注 |
| 加课 | 右下角 `+`，手动添加一节课 |
| 导入 PDF | 右上角“导入”，选教务系统导出的 PDF 课表，浏览器本地解析后预览，可以“替换”或“合并” |
| 深色模式 | 设置里可切浅色 / 深色 / 跟随系统 |
| 作息设置 | 设置里能改每天的节数、每节课的上下课时间、开学日期、学期总周数、是否显示周末 |
| 备份 | 设置里可以导出 / 导入 JSON，换手机时用来迁移 |

第一次打开时，已经根据课表 PDF 预置好了 21 门课，直接就能看。

## 换一份课表

1. 打开页面，点右上角 **导入**；
2. 选择教务系统下载的 PDF（文件名类似 `XXX(2026-2027-1)课表.pdf`）；
3. 等一两秒，出现“读取到 N 门课”的预览；
4. 选 **替换全部**（丢掉旧的）或 **追加**（保留旧的），确认即可。

解析全部在浏览器里完成，PDF 不会上传到任何地方。

## 数据存在哪

- 存在你浏览器的 `localStorage`，键名 `timetable.v1`，按**网址**隔离；
- 手机和电脑各存各的，浏览器不同也不共享，所以换设备时用「导出 JSON」→「导入 JSON」迁移；
- 清除浏览器数据 / 无痕模式会丢，重要改动记得导出备份。

## 更新网站（维护用）

1. 改本地文件（`index.html`、`assets/`）；
2. 运行：

```powershell
python .tools/gh-publish.py --token ghp_xxxxxx
```

脚本会通过 GitHub API 提交并触发 Pages 重建，约 30 秒后生效（手机刷新即可）。
仓库地址：<https://github.com/YRZ-cangyi/timetable>

## 文件结构

```
index.html              页面
assets/css/app.css      样式（含深色模式、桌面适配）
assets/js/core.js       数据模型、日期周次、本地存储
assets/js/pdf-parse.js  PDF 文本 → 课程（解析表格坐标）
assets/js/app.js        界面与交互
assets/js/seed.js       首次打开时预置的课表
vendor/pdfjs/           PDF.js 2.16.105 + 中文字体映射（离线内置）
.tools/gh-publish.py    发布脚本（维护用）
```

## 已知限制

- 只支持“文字版”PDF 课表；扫描件（图片）解析不出来，需要手动添加。
- 不同学校的课表模板不一样，导入结果的课程名或周次不对时，把 PDF 发我，我改解析规则。
- 免费 GitHub 账号的 Pages 只能从**公开仓库**发布，所以页面源码和预置的课表数据是公开的；课表 PDF 原件没有上传。
