# 我的课表 · 手机端课表工具

一个纯前端的小工具：双击 `index.html` 就能用，不需要联网、不上传任何数据，课表只存在你自己的浏览器里。

## 打开方式

- **电脑**：双击 `index.html`（推荐用 Chrome / Edge）。
- **Android 手机（方式一，推荐）**：双击 `手机预览.bat`，电脑会打印一个 `http://192.168.x.x:8787` 的地址，
  手机连**同一个 Wi-Fi**，用 Chrome 打开这个地址即可；想固定在桌面就点 Chrome 菜单里的「添加到主屏幕」。
  电脑要关掉窗口页面才会失效（数据仍然存在手机浏览器里，下次再开还在）。
- **Android 手机（方式二，纯离线）**：把整个文件夹拷到手机（例如 `Download/课表`），
  用文件管理器点 `index.html` →「用其他应用打开」→ Chrome。部分机型会拦截本地文件的 `file://` 访问，打不开就用方式一。

> iPhone 的 Safari 不允许直接打开本地 HTML，需要用方式一（电脑常开）或把文件夹传到静态托管上。

## 功能

| 功能 | 说明 |
| --- | --- |
| 周课表 | 第 1 周周一按 `2026-09-07` 计算，星期一到星期日全显示 |
| 换周 | 左右滑动屏幕，或点顶部的 `‹` `›`；`本周` 一键回到当前周 |
| 看详情 | 点任意一节课程，弹出名称、时间、地点、第几节、哪些周、备注 |
| 编辑 | 详情里点“编辑”，可改名称、老师、地点、星期、节次、周次、颜色、备注 |
| 加课 | 右下角 `+`，手动添加一节 |
| 导入 PDF | 右上角“导入”，选教务系统导出的 PDF 课表，本地解析后预览，可以“替换”或“合并” |
| 深色模式 | 设置里可切浅色 / 深色 / 跟随系统 |
| 作息设置 | 设置里能改每天的节数、每节课的上下课时间、开学日期、学期总周数 |
| 备份 | 设置里可以导出 / 导入 JSON，换手机时用来迁移 |

第一次打开时，已经根据 `闫镕泽(2026-2027-1)课表.pdf` 预置好了 21 门课，直接就能看。

## 换一份课表

1. 打开页面，点右上角 **导入**；
2. 选择教务系统下载的 PDF（文件名类似 `XXX(2026-2027-1)课表.pdf`）；
3. 等一两秒，出现“读取到 N 门课”的预览；
4. 选 **替换全部**（丢掉旧的）或 **追加**（保留旧的），确认即可。

解析全部在浏览器里完成，PDF 不会离开你的电脑。

## 数据存在哪

- 存在浏览器的 `localStorage`，键名 `timetable.v1`；
- 换浏览器、清除浏览数据会丢，所以重要的话在设置里 **导出 JSON** 备份；
- 隐私模式 / 无痕模式下数据关掉窗口就没，建议正常窗口使用；
- 用 `手机预览.bat` 的局域网地址打开时，数据是跟着**网址**存的：如果路由器换了 IP（比如 `192.168.1.5` 变成 `192.168.1.9`），
  页面会像“第一次打开”一样变成预置课表。用固定 IP / 静态托管更稳，改过的东西记得先导出一份 JSON。

## 放到手机上用（可选）

如果不想拷文件，可以把整个文件夹传到任意静态托管（GitHub Pages、Vercel、Netlify 都行），
然后在手机浏览器打开那个网址，再用“添加到主屏幕”，用起来和 App 差不多。

## 文件结构

```
index.html              页面
手机预览.bat            一键起局域网服务，手机同 Wi-Fi 打开
assets/css/app.css      样式（含深色模式、桌面适配）
assets/js/core.js       数据模型、日期周次、本地存储
assets/js/pdf-parse.js  PDF 文本 → 课程（解析表格坐标）
assets/js/app.js        界面与交互
assets/js/seed.js       首次打开时预置的课表（由 PDF 生成）
vendor/pdfjs/           PDF.js 2.16.105 + 中文字体映射（离线内置）
.tools/                 开发和测试脚本（用不到可以删）
```

## 已知限制

- 只支持“文字版”PDF 课表；如果是扫描件（图片），解析不出来，需要手动添加。
- 不同学校的课表模板不一样，如果导入结果的课程名、周次不对，把 PDF 发我，我改解析规则。
- 部分 Android 机型不允许 Chrome 打开 `file://` 本地网页，用 `手机预览.bat` 起局域网地址即可。
- `手机预览.bat` 依赖电脑上装有 Node.js 或 Python；两个都没有时，只能拷文件用。
